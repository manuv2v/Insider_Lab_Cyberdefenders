##  Descripción general

Resolución del laboratorio **Insider** de Cyberdefenders. En el que se detalla los pasos, problemas y técnicas relevantes para la superación de este lab. Con el objetivo de adquirir conocimiento y habilidad para el desarrollo personal en la ciberseguridad, y más concretamente a la parte que más me gusta, la defensa y forense digital.

##  Descripción del Lab

Analizar los artefactos de imágenes de disco de Linux, incluidos los registros y el historial de Bash, utilizando FTK Imager para investigar actividades de amenazas internas y reconstruir las acciones de los usuarios.

##  Escenario

Después de que Karen comenzara a trabajar para «TAAUSAI», empezó a realizar actividades ilegales dentro de la empresa. «TAAUSAI» te contrató como analista social para iniciar una investigación sobre este caso.

Obtuviste una imagen de disco y descubriste que Karen utiliza el sistema operativo Linux en su ordenador. Analiza la imagen de disco del ordenador de Karen y responde a las preguntas que se te plantean.

##  Objetivos del laboratorio

- [x] Análisis e investigación de adquisición de datos.
- [x] Análisis de logs e historico bash.

### Herramientas utilizadas

- **FTK Imager** - Herramienta de adquesición, examen y análisis de datos de almacenamiento digital.
